# PulseDB

<p class="lede">Turn any Confluence Database into live charts and KPI cards, right on your Confluence pages.</p>

Confluence Databases are a great place to track budgets, roadmaps, and requests. PulseDB adds the missing piece: a quick way to show what the data means. Insert the PulseDB macro on a page, pick a database, and choose a chart. The chart reads the database live every time the page is viewed, so it is never out of date.

## What it does

| | |
|---|---|
| **Six visual types** | KPI summary card, bar, horizontal bar, donut, pie, and line charts |
| **Real calculations** | Count rows, or sum, average, minimum, or maximum any number column |
| **Smart grouping** | Group by a choice, person, text, checkbox, or date column (by day, week, month, quarter, or year) |
| **One-rule filter** | Show only rows that match, such as "Status is Approved" or "Amount over 20,000" |
| **Units** | Add "$", "%", or any symbol, and choose decimal places |
| **Light and dark mode** | Follows each reader's Confluence theme automatically |

## Built to be trusted

- **Runs on Atlassian.** PulseDB runs entirely on Atlassian's own cloud platform. It makes no connections to outside servers and sends no analytics anywhere.
- **Respects permissions.** Charts are built from the data the *person viewing the page* is allowed to see. If they can't open the source database, they see a short note instead of the data.
- **Stores nothing.** PulseDB keeps no copy of your data. Chart settings are saved by Confluence as part of the page.

Read more on the [Data &amp; security]({{ '/security/' | relative_url }}) page.

## Get started

1. Install PulseDB from the Atlassian Marketplace.
2. On any Confluence page, type `/PulseDB` and press Enter.
3. Choose a database, a chart type, and what to measure, then click **Save**.

The [User guide]({{ '/user-guide/' | relative_url }}) walks through every option.
